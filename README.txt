AGNEX Digital Studio — website starter package

Files: index.html, styles.css, script.js, favicon.svg, visitor-count.php, robots.txt, sitemap.xml

Deployment:
1. Back up the existing agnexdigital.com public_html contents before uploading.
2. Upload the contents of this package (not the enclosing folder) to the agnexdigital.com public_html directory.
3. Ensure PHP is enabled and that the parent directory of public_html is writable by the PHP process for the visitor-count file.
4. Visit https://agnexdigital.com/ and check the visitor counter. If the counter says unavailable, check server write permissions/logs. Do not move the data file into public_html.

IMPORTANT BEFORE PUBLIC LAUNCH:
- The enquiry form is MAILTO ONLY: it opens the visitor's email application. It does not send mail from the website. The address hello@agnexdigital.com is a proposed placeholder and MUST be replaced with an actual working mailbox. Configure a secure PHP/SMTP handler separately before offering direct form submission.
- The portfolio section includes Evercrest International as a sample. Obtain the client's permission to display it before public launch.
- Review business claims, privacy policy requirements and contact details before launch.
- Visitor counter counts at most once per browser per 24 hours using a first-party cookie. It does not identify unique people, and counts may be affected by blocked cookies or automated traffic. The count is stored outside public_html in agnex-visitor-count.txt.
- The text brand and favicon are placeholders until the logo is finalized.
